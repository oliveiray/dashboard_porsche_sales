# Project Dashboard_Porsche_Sales

*Quais perguntas de negócio você escolheu, e por quê*
Escolhi as seguintes perguntas de negócio, pois trazem informações comumente relevantes em dashboards de vendas:
* modelo mais vendido
* ano do carro mais vendido
* forma de pagamento mais utilizada
* informacoes relevantes dos pedidos cancelados

*O prompt que gerou a dashboard, e o que mudou nele até a versão final*
utilize a planilha em anexo para criar um dashboard em HTML no Canvas.

utilize os seguintes filtros:
- vendas por modelo
- vendas por ano
- vendas por estado
- formas de pagamento por estado

crie caixas específicas trazendo os seguintes insights:
- modelo mais vendido
- ano do carro mais vendido
- forma de pagamento mais utilizada
- informacoes relevantes dos pedidos cancelados

utilize uma ui/ux no estilo do site oficial da Porsche BR (https://www.porsche.com/brazil/pt/)

*Que tratamento a base precisou antes de ir para a IA*
* Exclui as colunas não sanitizadas.
* Tratei as entradas INVALID da coluna sale_date.
* Transformei em número os campos das colunas model_year e vehicle_mileage

*Se você usou o ChatGPT com Canvas, um agente com skill, ou os dois*
Utilizei somente o ChatGPT com Canvas. Utilizei também o Gemini para tirar algumas dúvidas sobre o GitHub e VS Code que tive ao longo da criação do projeto.
